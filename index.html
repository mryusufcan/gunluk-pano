GitHub yayını

Değişiklikler GitHub'daki content.json dosyasına yazılır; GitHub Pages 1-2 dakikada günceller.

Anahtarınız yoksa: GitHub'da anahtar oluştur → Repository access: Only select repositories (gunluk-pano) → Permissions: Contents: Read and write → Generate.

Anahtar oluşturmadan da yayınlayabilirsiniz: GitHub'da content.json'u düzenle → content.json kopyala ile aldığınız metni yapıştırıp commit edin.

Nasıl kurulur?
  1. GitHub'da depoyu oluşturun ve bu klasörü yükleyin; Settings → Pages → Source: GitHub Actions.
  2. GitHub → Settings → Developer settings → Fine-grained tokens → yeni anahtar: yalnızca bu depo, izin Contents: Read and write.
  3. Anahtarı buraya yapıştırın, Ayarları kaydet ve Bağlantıyı dene.
  4. Her düzenlemeden sonra Yayınla. Ekip sayfayı yenilediğinde yeni hâli görür.

Veri

Nasıl çalışır?

Bu sayfa salt görüntüleme içindir. İçerik yönetici tarafından content.json dosyasına yayınlanır; siz sayfayı açtığınızda son sürüm gelir. Güncelleme gelmediyse üstteki yenile düğmesine dokunun.

Yönetici modundasınız. Değişiklikler önce bu cihazda taslak olarak tutulur, Yayınla ile GitHub'a yazılır. Ekip sayfayı yenilediğinde yeni hâli görür.

Ekip ve yemek listelerini elle yazmak zorunda değilsiniz: Listeden içe aktar ile Excel, Word veya WhatsApp metnini yapıştırın ya da .xlsx / .docx dosyası seçin.

Günün özetini ekip grubuna göndermek için üstteki paylaş düğmesini kullanın.

Ana ekrana ekle (isteğe bağlı)

  • iPhone: Safari → Paylaş → Ana Ekrana Ekle.
  • Android: Chrome → ⋮ → Ana ekrana ekle.
  • Simge eklenince site uygulama gibi tam ekran açılır.
